# LitPrism v1.0.0 发布说明（草稿）

> Windows 10 / 11（64 位）。

## 这一版带来的能力

v1.0.0 把「发现文献 → 核对真伪 → 读懂原文 → 人工确认 → 做标注 → 带出处提问 → 备份迁移」连成了一条完整的工作流程。

| 模块 | 你能做什么 |
|---|---|
| **找得到、核得准** | 按主题检索文献，逐篇核对标题、作者、DOI；不存在的论文进不了知识库 |
| **拿得到全文** | arXiv 直接取回；其他论文自动寻找合法开放副本；订阅文献给你原文链接，下载后可导入并自动关联到候选 |
| **读得明白** | 按章节阅读原文，自动提炼研究问题、方法、实验与结论，每条陈述都带原文出处 |
| **确认由你做主** | 机器给的结论只是候选；确认、修订、撤销都由你决定，过程可追溯 |
| **留下自己的理解** | 选中原文写批注，跨论文汇总、一键回到原句，可导出 Markdown 或 CSV |
| **问得有依据** | 基于你确认过的材料提问，回答带可点击的出处编号，可限定论文范围 |
| **数据拿得走** | 一键备份与恢复，原始附件按版本保留，文献可导出、可回收 |

## 安装与升级

- Windows 10 / 11（64 位）。从 [Releases](https://github.com/kingjone0/litprism/releases) 下载安装包。
- 从 v0.1.x 覆盖安装即可，本机文献与标注会保留。
- 首次使用需要配置模型；没有配置时仍可浏览界面、阅读已导入的文献。

技术说明与已知边界见 README「技术说明与边界」一节。
