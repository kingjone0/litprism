# 安装生命周期在云上跑（方案，2026-10-29）

回答一个问题：**没有干净机器时，能不能用云服务验 F3 的安装/卸载？**
结论：能覆盖大部分，但有三项覆盖不了。下面是可用范围、前置条件和可直接用的工作流。

本页是方案，不是已完成项。[缺陷台账](缺陷台账-2026-10-29.md) 的 D6 仍为待验。

## 能覆盖什么

GitHub Actions 的 `windows-latest` 每次都是一个全新 Windows Server VM，用完销毁 —— 天然满足"干净机器"。

| 验收项 | 能否覆盖 | 怎么验 |
|---|---|---|
| 静默安装 | ✅ | `LitPrism-Setup-0.1.0.exe /S`，检查退出码与落位 |
| 安装内容完整 | ✅ | 校验 `LitPrism.exe`、`resources/litprism-sidecar.exe`、卸载器 |
| 启动 | ✅ | 启动 `LitPrism.exe`，轮询主窗口进程存活 |
| 内置 sidecar 可用 | ✅ | 断言子进程是安装目录下的 `litprism-sidecar.exe`，不是系统 python |
| 数据目录创建 | ✅ | 安装后首次启动，检查 `%APPDATA%` 下的数据目录 |
| 静默卸载 | ✅ | `"Uninstall LitPrism.exe" /S`，检查目录与注册表项清除 |
| 重装后数据保留 | ✅ | 卸载前写入标记文件，重装后检查仍在 |
| 多屏行为 | ❌ | runner 只有单个虚拟显示器 |
| 真实 GPU 渲染/性能 | ❌ | Server 镜像无独显；本应用本就 `disable-gpu`，影响有限但验不了 |
| "没装 Python 也能跑" | ⚠️ 只能间接证明 | runner 镜像自带 Python，无法构造"无 Python"环境。可证明的是 sidecar 是 PyInstaller 单文件、运行的是包内二进制 |

## 前置条件

1. **安装包不要走 Actions artifact**：258.9 MB，免费 artifact 存储只有 500 MB，两次就撑爆。
   挂到 **Release 资产**（单文件上限 2 GB，不占 Actions 存储）。
2. 仓库需要 Actions 开启；`workflow_dispatch` 手动触发，不会在 push 时自动跑。
3. 安装是 **per-user**（`perMachine=false`），落点是 `%LOCALAPPDATA%\Programs\LitPrism`，
   不需要管理员；runner 默认管理员且 UAC 已关，权限不是障碍。

## 工作流（可直接放进 `.github/workflows/install-lifecycle.yml`）

```yaml
name: install-lifecycle

# 只手动触发：避免每次 push 都跑一次 258MB 的安装卸载
on:
  workflow_dispatch:
    inputs:
      release_tag:
        description: '含安装包的 Release tag（如 v0.1.0）'
        required: true

jobs:
  windows:
    runs-on: windows-latest
    timeout-minutes: 30
    steps:
      - uses: actions/checkout@v4

      - name: 下载安装包
        shell: pwsh
        env:
          GH_TOKEN: ${{ github.token }}
        run: |
          gh release download "${{ inputs.release_tag }}" --pattern "LitPrism-Setup-*.exe" --dir "$env:RUNNER_TEMP\pkg"
          Get-ChildItem "$env:RUNNER_TEMP\pkg"

      - name: 静默安装
        shell: pwsh
        run: |
          $setup = (Get-ChildItem "$env:RUNNER_TEMP\pkg\LitPrism-Setup-*.exe").FullName
          $p = Start-Process $setup -ArgumentList '/S' -Wait -PassThru
          "退出码: $($p.ExitCode)"
          if ($p.ExitCode -ne 0) { throw "安装失败 $($p.ExitCode)" }

      - name: 校验落位
        shell: pwsh
        run: |
          $dir = "$env:LOCALAPPDATA\Programs\LitPrism"
          foreach ($f in @('LitPrism.exe', 'resources\litprism-sidecar.exe', 'Uninstall LitPrism.exe')) {
            $path = Join-Path $dir $f
            if (-not (Test-Path $path)) { throw "缺文件: $path" }
            "OK $f"
          }

      - name: 首次启动并确认内置 sidecar
        shell: pwsh
        run: |
          $dir = "$env:LOCALAPPDATA\Programs\LitPrism"
          $app = Start-Process (Join-Path $dir 'LitPrism.exe') -PassThru
          Start-Sleep -Seconds 25
          # sidecar 必须是安装目录里的二进制，不是系统 python —— 这是"包内自带运行时"的直接证据
          $sc = Get-CimInstance Win32_Process -Filter "Name='litprism-sidecar.exe'" |
                Select-Object -First 1
          if (-not $sc) { throw 'sidecar 未启动' }
          "sidecar: $($sc.ExecutablePath)"
          if ($sc.ExecutablePath -notlike "$dir*") { throw "sidecar 不在安装目录: $($sc.ExecutablePath)" }

          # 数据目录（Electron userData，按产品名或包名二选一）
          $candidates = @("$env:APPDATA\LitPrism", "$env:APPDATA\litprism-desktop")
          $dataDir = $candidates | Where-Object { Test-Path $_ } | Select-Object -First 1
          if (-not $dataDir) { throw '未找到数据目录' }
          "数据目录: $dataDir"
          "DATA_DIR=$dataDir" | Out-File "$env:GITHUB_ENV" -Append -Encoding utf8

          # 写标记，供卸载重装后核对数据保留
          'keep-me' | Out-File (Join-Path $dataDir 'ci-retention.marker') -Encoding utf8
          Stop-Process -Id $app.Id -Force
          Get-Process litprism-sidecar -ErrorAction SilentlyContinue | Stop-Process -Force
          Start-Sleep -Seconds 3

      - name: 静默卸载
        shell: pwsh
        run: |
          $dir = "$env:LOCALAPPDATA\Programs\LitPrism"
          $p = Start-Process (Join-Path $dir 'Uninstall LitPrism.exe') -ArgumentList '/S' -Wait -PassThru
          "退出码: $($p.ExitCode)"
          Start-Sleep -Seconds 8
          if (Test-Path (Join-Path $dir 'LitPrism.exe')) { throw '卸载后主程序仍在' }

      - name: 重装并核对数据保留
        shell: pwsh
        run: |
          $setup = (Get-ChildItem "$env:RUNNER_TEMP\pkg\LitPrism-Setup-*.exe").FullName
          $p = Start-Process $setup -ArgumentList '/S' -Wait -PassThru
          if ($p.ExitCode -ne 0) { throw "重装失败 $($p.ExitCode)" }
          $marker = Join-Path $env:DATA_DIR 'ci-retention.marker'
          if (-not (Test-Path $marker)) { throw "重装后数据丢失: $marker" }
          "数据保留 OK"
```

## 落地顺序

1. 把 `LitPrism-Setup-0.1.0.exe` 传到一个 Release（tag 例如 `v0.1.0`）。
2. 建 `.github/workflows/install-lifecycle.yml`，粘贴上面内容。
3. 手动触发一次，看日志逐条通过。
4. 通过后，把结果记进[缺陷台账](缺陷台账-2026-10-29.md) D6，并注明"多屏与 GPU 未覆盖"。

## 其他可选项

| 服务 | 适合度 | 说明 |
|---|---|---|
| GitHub Actions `windows-latest` | 首选 | 公有库 4 核 / 16 GB / 14 GB SSD 且不限分钟；私有库 2 核 / 8 GB，每月 2000 分钟 |
| AppVeyor | 备选 | 老牌 Windows CI，开源免费，配置比 Actions 老派 |
| Cirrus CI | 备选 | 支持 Windows/macOS VM，按需计费 |
| Azure Pipelines | 备选 | 有 hosted Windows agent，生态重一些 |
| GitHub Codespaces | **不行** | 只有 Linux 容器，跑不了 Windows 安装包 |
| Windows 365 / AVD | 真机替代 | 有真实桌面和多虚拟显示器，但要付费；只有在必须验多屏时才值得 |

## 边界

- 云上通过 ≠ 可交付。真实用户机器上的杀软拦截、中文路径、系统语言、旧版本升级路径仍需本地验证。
- 本方案只验"装得上、跑得起来、卸得干净、数据不丢"，不验功能正确性（那由 pytest 与 UI 巡检负责）。
