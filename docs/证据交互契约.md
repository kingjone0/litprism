# 证据交互契约

更新：2026-10-24。当前 chat 的完整范围、状态和接口以[M04契约](M04对话侧缺口与设计-2026-10-21.md)为准；本页维护各模块共同的证据交互底线。历史实验数字见专项报告，不作为当前能力承诺。

## 回复和右栏

- 回复后来源链接绑定稳定 chunk/source ID，P 编号仅本轮有效；模型不能决定来源标题、URL、物理页、取得时间或审核状态。
- 点击右栏显示实际文本、来源类型、原始地址/论文、物理页或无页码、材料范围、审核依据和当前可用性。查看与原句高亮均不代表语义支持。
- 论文当前/历史材料分开，搜索摘要不当网页正文，原文送达不当理解完整。服务思考不作证据。
- 重开仍检查来源；失效引用不能继续支撑正常结论，可保留明确标为仅回溯的历史链接，不替换成其他来源。

## 本轮使用与可信入库分开

| 来源 | 本轮回答 | 后续全库检索 |
|---|---|---|
| 已核验/人工确认论文原文 | 可用；保留核验与材料版本 | 按当前材料和可信状态读取 |
| 人工确认知识/网页快照 | 按有效依赖使用，历史依据明确标识 | 可检索；撤销或依据失效停止自动引用 |
| 本轮实际搜索取得的 pending 摘要 | 本轮授权后可用，程序标出搜索摘要/未审核及取得时间 | 不自动获得可信知识准入 |
| 其他待审快照、任意用户或模型提供的 URL | 不因有链接而可引用 | 人工确认前不可用 |
| 被拒绝/撤销的来源 | 不可用 | 不可用；保留审核历史 |

当前Web界面默认综合全库相关可信知识与本轮联网证据，只保留可选回答范围；主动限定论文/分组时不扩范围、不联网。授权绑定本轮用户消息和内容哈希，不能用别的待审快照冒充本轮来源。聊天未选论文或空列表表示不限定；全库检索不是全库全文全部送达。无效/已删除选择不能静默变全库，明确选择的空分组保留过滤。历史focus/strict、显式web_search=false及精确续验保留原语义，不批量改写旧范围或请求。

## 人工知识和上游变化

用户在右栏选择实际来源、修订正文和填写依据，生成独立人工知识及结构化来源依赖。只有修订正文进入检索，附带原文和审核说明仅保留供审计。可以针对本轮网页摘要确认一条知识，而不确认整份网页。原生成与机器状态不覆写；新知识参与后续正常检索，旧回答及相关旧摘要在人工裁决后退出上下文。

上游回收/拒绝/撤销或内容变化会影响派生知识的当前可引用性，并沿依赖传播；人工确认历史保留，受影响知识待复核。材料换版标明历史依据，不自动宣判旧知识错误。网页临时打不开与内容失效不同，保留已取得的快照。旧派生知识没有结构化依赖时不猜测恢复其来源关系，明确待重新核对。

偏好只能影响表达，不承载事实知识。确认后的内容也不是不可撤销的真理证明。修订入库、拒绝和撤销均绑定版本哈希与审核状态，旧哈希/重复提交不得覆盖新结果。

## 审核颗粒度

引用存在性、原句定位、机器语义支持和人工确认分开记录。辅助映射缺项/格式错误只作提示；明确排版等价保留原文位置，不改数字、否定或对象。虚构来源、错页、失效来源和已知证据风险仍阻止相关结论。尚不能可靠分割影响范围时隔离整答，不自动删句伪装修复；不宣称已有通用逐句蕴含审核。

回答可忠实转述；quotes 才需对应绑定块内的实际原文。获取时间/来源说明/历史标记按程序记录单独核对完整字段，右栏注明非论文原句，不给它捏造正文偏移或当作学术结论证明。不因程序字段定位失败误隔离整答，也不把真实错绑引句一律降为告警。

默认关闭的锚点试验只改变原文定位方式：模型可选择程序给出的版本/内容绑定锚点，程序回填实际文本与偏移。锚点不证明陈述受支持；错误来源、过期锚点或附带错引仍阻断，人工审核与来源生命周期守卫不变。普通聊天仍走旧式quotes校验，未全量切换。

QA新格式优先使用answer_units，由程序把同一text展示为回答并生成陈述位置，不要求模型再抄写/概括claim。唯一字面对应、未绑定和重复歧义分开记录；旧格式和旧快照明确兼容/未知，不从相似文字猜测绑定。准确对应只证明陈述来自已展示回答，不证明原文支持它；结构冲突不静默选择，也不追加模型重写请求。

试验目录v2使用短句/短段精确字符范围，长段可分别选择相邻锚点。旧段落ID可还原原选择，但不会被静默缩短成某条“最相关”原句。摘要/全文、来源/材料版本、内容哈希和页码边界不变；分割边界不是语义完整性证明。右栏短原文仍可跳到完整来源，分段提示查看前后文。

## 共同验证要求

验证链接/重开/失效、混合来源标识、本轮授权不扩为全库准入、人工修订后重检索、传递依赖、撤销、并发版本检查、来源变化后的导出与恢复，以及深浅主题/窄屏/键盘操作。通过本地桩不代表真实联网、模型学术语义或完整长会话质量通过。

解读/对比人工审核仍绑定分析哈希与陈述 ID；机器复核/差异范围及当前数据版本见[M03](modules/03-阅读提取与协作审核.md)。旧 call_budget 等字段只作历史失败兼容，当前不重新引入阶段调用上限。


## 单元人工裁决

只有可靠回答位置才提供单元入口。确认、修订、拒绝、撤销使用独立令牌与审计；不连带确认兄弟单元或整答。人工正文和所选证据进入独立知识，原答/原模型选择不可变，未审部分不进入知识索引或自动事实历史。

右栏区分原回答所选证据与可补选上下文；人工可补选本轮实际送达来源的前后句，须逐处勾选。源ID、版本、内容哈希、页码和有效状态在提交时再核对，人工补选不伪装成模型原选。旧未知绑定不猜测修补，仍保留整答入口。

主对话保持连续原回答，回复后仅保留“核对回复并整理为知识”入口。右栏列出可靠绑定的回答单元，原位展开一条证据/修订表单，整答表单收进兼容入口。已选细原文仍能通过版本/内容校验时自动预选，核对正确即可保留，不要求人工重新寻找。所选原文优先显示，其余同来源原句默认折叠；其他本轮来源可按编号、标题或页码筛选，默认优先当前单元相关来源。不能定位的旧选择不猜测补配。普通正常回答不要求先人工审核；保存为可信知识是可选操作。

退出模型事实历史不等于从用户界面隐藏。主区保留原回答和汇总状态，逐条状态与人工正文在右栏展示。全部有效确认后显示全部条目已确认入库；拒绝、撤销、知识依赖失效、尚未处理或存在未对应正文分别计数，不永久标“整答未确认”，也不推断未知正文已审核。后续模型仍须重新检索有效知识。来源失效或原有语义拦截仍优先，不能借展示恢复被阻止的结论。通用定位说明与辅助记录缺陷分开呈现，不把定位免责声明当成待审错误。

首次裁决锁定整答或单元模式，不能混写。单元修订原子撤销旧知识/建立新版本，失败回滚；通用来源入口不能恢复由单元管理的旧版本。拒绝/撤销可在来源失效时执行；备份恢复、上游撤销及下游知识失效仍适用原依赖规则。人审动作不认证整篇材料或其余原答，脚本操作者验收也不是用户人工确认。
