## 当前聊天与证据路径

1. 默认没有限定论文时，检索相关全库论文、人工可信知识并取得实际联网摘要。空选择表示不限定；非法ID报错。主动选论文/分组时只用该范围、不联网；明确空分组保留过滤。
2. 能装下时，严格范围送达全部当前材料；默认范围补齐相关论文当前材料。“概述/比较”不再直接指定全库，按实际问题原词和当前追问来源确定相关论文，无原词命中时回退正常扩展；明确集合概览保留全库，真正多篇按原词分别召回。装不下仍按逐篇、命中章节、片段兜底，保留知识/网页，不改变会话范围和联网设置；词法命中仍可能有噪声。
3. 同次生成以answer_units形成唯一正文；question_items和addresses记录内部问题项关联。程序绑定正文位置，只检查声明后的结构；问题项完整性仍unknown、语义unreviewed，不进正文、不自动改稿或触发整答人审。
4. 来源编号/页码/当前可信状态、实际送达来源和原句定位分别核验；已知风险保留原稿供核对。正常回答保持连续正文，回复后单一入口在右栏逐条审核。
5. 人工确认产生独立知识，兄弟单元/父回答不被连带确认。原答和覆盖它的旧摘要退出事实历史，新知识由后续正常检索取得；上游撤销/换版影响派生可用性。

搜索摘要仍是摘要，不是网页正文或自动可信知识。原句可定位、内部关联齐全、answered都不证明语义正确。细则见[M04契约](M04对话侧缺口与设计-2026-10-21.md)。

## 当前阅读、复核与材料口径

P系列在完整消息装得下时使用固定全文前缀和真实目标范围指令，超窗沿原文完整分批；不是固定六字段各调用一次。原文块保留物理定位，全文指全部已索引材料，不证明原PDF已完整解析。

提取覆盖按章节统计，参考文献不计；机器条数与闸门只是技术信号。PDF书签优先、每指令陈述配额上限24、指令间有界概要是当前实现参数，不是正文完整性证明。未产出与有产出但未过闸门分开报告。

全部提取后、机器复核前独立保存ac_候选；机器关闭或失败仍能人工核对。能力已知时复用全文并批量核对，未知能力保留逐条兼容路径。六字段/对比的有界语义复核不自动扩展到QA、术语和Skill；同字段差异不是跨字段全量一致性。详见[M03](modules/03-阅读提取与协作审核.md)及[N01](阶段预算与可续验进度-2026-10-18.md)。

## 数据、模型与恢复边界

- 论文仅verified/manual_confirmed可引用；likely需人工放行，not_found和unchecked区分无匹配与服务失败。机器支持不改变人工可信状态。
- P编号属于单次请求；稳定链接保存chunk/source ID、材料版本与内容哈希。回收、撤销、换版不静默替换原来源；物理页不保证等同印刷页。
- Web/CLI/MCP共用同数据根ProviderStore当前选模；已选模型/凭据失效明确报错，不退mock。mock仅用于明确离线占位，不代表核验或外部能力也离线。
- 协议支持OpenAI Chat Completions/Anthropic Messages；Key走SecretStore，Windows默认DPAPI，弱存储降级必须明确。数据库只存引用，文档与测试夹具不存Key。
- API明确能力优先，Flash缺项按已确认1M/384K默认；只读展示并自动分配输出，推理占输出，无手工任务额度界面。服务上报缺项/未知用量不作零计费；本轮900秒等待是验收设置，不泛化为所有入口策略。
- N01单篇和新持久Web先存响应/用量再发布；重启不自动重发。成功精确复用，失败/未知须明确重试；来源、模型、历史或实现变化要求新请求。旧重新解读、对比、Skill、一次性CLI/MCP不自动获得持久恢复。
- N08在线快照、预检、仅恢复新目录、显式安排重启切换；密钥库不迁移，当前连接不热换。v15归档匹配v15，旧归档先用匹配版本恢复再迁移。日常库本轮未迁移或写入。
