## N01 持久运行：当前流程

```mermaid
flowchart TD
    A[创建单篇分阶段运行] --> B[绑定原文与模型及实现版本]
    B --> BUDGET{阶段请求次数是否可用}
    BUDGET -->|是| C[发送前记录尝试并占请求次数]
    BUDGET -->|否| H[保存运行状态并保留原解读]
    C --> D[执行一个模型请求]
    D -->|成功| E[保存精确响应与实际参数及用量]
    E --> F{阶段是否继续}
    F -->|是| BUDGET
    F -->|结束| G[事务校验并保存新分析]
    D -->|失败或中断| H
    H --> I[用户选择恢复]
    I --> J{绑定版本仍相同}
    J -->|否| K[拒绝复用并要求新建]
    J -->|是| L[精确复用成功请求]
    L --> F
    J -->|仍有失败或未知尝试| M[须显式允许重试]
    M --> BUDGET
```

请求次数预算与输出 token 能力是两件事。成功响应精确复用，失败或 `started` 不自动重发；回放不算新质量样本。只有 N01 新入口具备这套完整持久运行路径，不能把它推广到旧重新解读、QA、对比、Skill 或全部 CLI/MCP。

依据：`analysis_runs.py`、`web/analysis_run_routes.py`，完整契约见[阶段预算与可续验进度](../阶段预算与可续验进度-2026-10-18.md)。
