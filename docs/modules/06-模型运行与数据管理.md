## N01 持久运行：当前流程

论文详情只保留“解读论文/重新解读”一个入口，先展示当前快照的题录/摘要/部分正文/已解析正文/未知范围，再按需关闭术语或机器复核，无手工阶段调用上限。新建明确产生新运行，发布前保留旧分析；运行中再次打开查看已有任务，同一应用内同论文不重复排队。失败、取消或中断后，从同一运行记录检查并恢复；失败或结果未知的尝试须显式允许重试，刷新/重开不自动发请求。创建回执丢失时先查看记录，不提供盲目重复提交。材料在准备与提交之间变化时拒绝静默换版；来源/模型/实现/分析版本恢复守卫保持。

列表将真实性、当前材料等级及是否已有解读分列。材料等级来自当前不可变快照，足够文本的摘要/未知材料可在注明范围后阅读；缺少可用文本不能先发模型再失败。`fulltext`显示为已解析正文，不认证解析完整。可从准备窗口查看当前材料或返回既有本地导入入口；不新建绕过核验的补正文通道。

提取完成的ac_候选可直接人工核对，关闭机器或后续复核失败不阻断该人工路径，仍须绑定材料和分析版本；不是每条指令完成即落候选，见[M03](03-阅读提取与协作审核.md)。

```mermaid
flowchart TD
    A[单一解读入口 查看当前材料范围] --> P{可用文本及来源有效}
    P -->|不足| S[补充材料或完成核验 不发送请求]
    P -->|可用| B[创建持久运行 绑定原文与模型及实现版本]
    B --> C[发送前记录尝试及请求参数]
    C --> D[执行一个模型请求]
    D -->|成功| E[保存精确响应与实际参数及用量]
    E --> F{阶段是否继续}
    F -->|是| C
    F -->|结束| G[事务校验并保存新分析]
    D -->|失败或中断| H[保存运行状态并保留原解读]
    H --> I[用户选择恢复]
    I --> J{绑定版本仍相同}
    J -->|否| K[拒绝复用并要求新建]
    J -->|是| L[精确复用成功请求]
    L --> F
    J -->|仍有失败或未知尝试| M[须显式允许重试]
    M --> C
```

## N09 统一选模与stdio边界

Web、CLI、MCP采用同一数据根的当前提供商/模型、协议和能力数据，Key仍只走SecretStore。仅明确mock配置在未选模型时可离线占位；所选模型失效不自动回退。MCP每次ask重新解析当前选择，检索工具不要求模型可用；CLI诊断明确基础配置与当前模型状态。

模块和CLI两种stdio入口均支持显式配置，stdout仅协议、诊断走stderr，退出按连接所有权回收。只读模式隐藏写工具，逻辑失败带isError/ok=false和审计原因；指定配置缺失/为空或无效CLI论文选择不得回落其他库/全库。已用本机SDK2.3.0完成握手、工具/资源调用、模式守卫、两协议本机HTTP桩与正常退出验收，详见[N09报告与使用方式](../N09配置与集成验收-2026-10-24.md)。

CLI/MCP的一次性问答仍是本地内核入口，不自动联网，也不提供持久Web对话的人审/续验；MCP对比只读取当前已存分析，与Web模型对比不同。宿主客户端安装、远端服务稳定性与跨机器环境尚未扩大验收。

## N10体验与管理边界

文献列表现在按全库条件查询并每页50条，服务端支持标题/显示标题/作者/摘要/标签与嵌套分组，显示真实匹配总数及页码。完整轻量目录供范围/管理选择，侧栏只展示20条速览并提供全部入口，不再把最近300篇当全库。翻页或切筛选清除旧勾选，失败停用旧选择并可原位重试，迟到响应不覆盖新页；页数因并发删除缩减时回退到有效页。会话可加载100条以后的记录，标题/消息查询仍在全库执行。接口和验证见[G01收口](../整体设计与实现缺口复核-2026-10-28.md#g01实现与收口2026-10-28)。

设置采用原生模态对话框，Tab留在当前任务、Escape只关闭最上层、关闭后归还焦点；窄屏导航覆盖工作区并在进入页面后收起。搜索/分组筛选移除不可见的勾选，批量动作不会继续作用于被隐藏的文献；导出弹窗固定本次选择，不因后台清空勾选回退全库。文献刷新清空对比缓存/来源；执行期间的文献变化、改选及更新请求使迟到结果失效。

分组移动/拖动/排序、回收/恢复等范围见[N10报告](../N10体验与管理验收-2026-10-25.md)，不替代N08全库恢复。窗口几何与最大化状态保存在独立数据根window-state.json；31项Node模拟不代表真实Electron实机，该缓存不进入知识备份。G05a聊天流式已接入并做本机/限定真实协议验证；生成中草稿不作为知识，后台重启不恢复未完成草稿，详见[持久聊天契约](../N04对话请求持久化与续验-2026-10-23.md#g05a真实流式与发布边界)。系统通知/托盘未纳入，F3仍暂停。
