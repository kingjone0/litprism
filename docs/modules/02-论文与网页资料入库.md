# M02 论文与网页资料入库

更新：2026-10-20。本页说明模块边界；“当前实现”与“修订目标/缺口”分开，后续实施顺序只维护在 [实现计划](../实现计划.md)。本轮新增 N12 材料版本化，详见 [实施契约](../N12原文材料版本化-2026-10-20.md)。

## 现有三条路径

| 路径 | 当前处理 | 能得到什么 | 尚未接通什么 |
|---|---|---|---|
| 本地文件 | 解析、题录补全、文献真实性核验/人工放行、保存原文块和 FTS5 | 有物理页定位的已解析材料；具体格式能力不同 | 扫描件可靠转写、复杂版式专项保障 |
| 学术搜索/推荐结果 | 核验可引用性，`import_record()` 保存题录并写“题录与摘要”块；**arXiv 候选可通过 `POST /api/candidates/{id}/fetch` 自动取 PDF 并升为全文** | 题录/摘要，或（arXiv）带物理页的全文 | 非 arXiv 来源的自动取全文与原始附件版本保管 |
| 普通网页搜索或手工文本 | 创建 `kind=web/knowledge`、`status=pending` 的内容快照；人工确认后可引用 | 搜索摘要或用户提供的文本，来源类型保留 | 自动抓取网页正文、解析清洗、识别论文链接后转入论文入库流程 |

## 当前流程

```mermaid
flowchart TD
    L[本地文件] --> PARSE[解析与题录补全]
    PARSE --> VERIFY[文献真实性核验或人工放行]
    A[学术搜索题录] --> VERIFY
    VERIFY --> OK{允许引用}
    OK -->|否| STOP[拒绝可引用入库并返回原因]
    OK -->|文件路径| FULL[保存论文及已解析原文块]
    OK -->|题录路径| ABSTRACT[保存论文及标题摘要块]
    W[网页搜索结果或粘贴文本] --> SNAP[保存 pending 快照]
    SNAP --> HUMAN[人工查看并确认或拒绝]
    HUMAN -->|确认| WEB[可引用的原类型快照]
```

人工确认文献真实性、人工确认网页快照、人工确认知识陈述分别记录，不是同一个动作。`verified/manual_confirmed` 只说明对应核验/审核状态，不能据此推导已取得全文。

## 缺少的内容获取接线

普通网页正文虚线是目标；用户仍可先保存题录，稍后补全文，而不是强制所有题录都先下载成功。

```mermaid
flowchart TD
    C[已选择的候选及来源标识] --> TYPE{材料类型}
    TYPE -->|论文题录或论文链接| META[论文身份核验]
    META --> BIB[题录可先保存并标注缺全文]
    BIB -->|arXiv 自动取回或用户本地上传| PDF[取得论文 PDF 或正文并保存材料版本]
    PDF --> PARSE[解析与清洗和物理定位]
    PARSE --> MATERIAL[与论文记录关联的原文材料]
    TYPE -->|普通网页| URL[原网页 URL]
    URL -. 待补正文获取 .-> TEXT[正文或明确的局部快照]
    TEXT --> REVIEW[保存来源快照及人工审核]
    TYPE -->|用户已有文件或文本| MANUAL[使用现有本地导入或快照入口]
```

前置应保留：来源 URL/数据库标识、抓取/导入时间、文本范围、内容哈希、论文版本、处理失败原因和材料完整度。搜索摘要、摘要、局部正文、全文应明确区分，不能用一个“已入库”标签掩盖差异。

材料完整度已落库（`papers.material_level`，schema v9）：题录导入=abstract/metadata，本地导入=fulltext，重复导入只升不降；解读与界面据此标注"仅题录/摘要"。

当前 `find_duplicate()` 保留 DOI 和标题/年份指纹去重。N12 的 `add_chunks()` 改为保存完整材料快照，默认不再追加；同内容幂等，默认检索只取 current，旧材料与原块 ID 保留。新旧分析绑定材料，历史分析可只读查看。已被混入的旧原文只回填一份 legacy 快照，不能自动拆出原来的真实版本。[N08](../N08备份恢复与目录迁移-2026-10-20.md) 已支持已解析材料和审核历史的一致备份、可选托管原文备份；外部原始附件追踪和不可变的逐版本附件保管仍未实现。

**当前风险边界**：P 系列的 `whole` 表示全部“已索引块”进入请求；若某论文仅有摘要块，不能把它称作整篇论文已读完。材料完整度提示与进入全文解读前的产品级识别仍需补齐，本轮不宣称代码已经阻止了所有这类误用。
