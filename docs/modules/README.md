# 功能模块导航

当前功能按六个职责模块组织，避免把所有入口压成一条“导入文件 → 模型复核 → 知识库”。端到端关系与原设计冲突见 [总览及流程图](../当前设计与功能流程图.md)，测试/真实服务状态只看 [当前状态](../当前实现与验收状态.md)。

| 模块 | 负责什么 | 输入 → 输出 | 边界文档 |
|---|---|---|---|
| M01 来源发现与候选 | 研究问题、学术/网页检索、推荐和候选筛选 | 查询/种子论文 → 候选记录 | [来源发现与候选](01-来源发现与候选.md) |
| M02 论文与网页资料入库 | 题录核验、内容获取、解析、定位、去重与版本 | 文件/题录/URL/文本 → 论文材料或待审快照 | [论文与网页资料入库](02-论文与网页资料入库.md) |
| M03 阅读提取与协作审核 | P 系列提取、机器辅助、人工裁决 | 已取得材料 → 有来源的候选和审核记录 | [阅读提取与协作审核](03-阅读提取与协作审核.md) |
| M04 检索问答与研究 | 范围检索、RAG、追问、跨论文对比与关联 | 研究问题/文献集合 → 带来源回答或研究结果 | [检索问答与研究](04-检索问答与研究.md) |
| M05 知识沉淀与产出 | 知识快照、人工确认/撤销、产出与导出 | 候选/人工知识/研究结果 → 可追溯知识或交付物 | [知识沉淀与产出](05-知识沉淀与产出.md) |
| M06 模型运行与数据管理 | Provider/SecretStore、能力、持久任务、隔离与管理 | 任务与本地状态 → 可观测和可恢复的运行 | [模型运行与数据管理](06-模型运行与数据管理.md) |

模块是职责划分，不代表已拆成六个独立服务或数据库。论文、网页候选、知识快照可以都存在本地 SQLite，但可信状态和使用范围不同。

## 三种“入库”不能混用

| 用语 | 当前对象/状态 | 代表什么 | 不代表什么 |
|---|---|---|---|
| 候选暂存 | 统一 `source_candidates` 候选池；网页内容快照另存 `evidence_sources.status=pending` | 为用户保留待筛选、待核对材料 | 已审核或可作事实依据 |
| 论文材料入库 | `papers` + `materials` + `chunks` | 可能只有题录/摘要，也可能有已解析的 PDF 原文 | 一定已取得全文、表格已理解或知识已确认 |
| 可信知识沉淀 | `kind=knowledge`、人工确认的来源快照及审计 | 用户核对并愿意作为后续依据使用，仍可撤销 | 已被证明永远正确 |

论文真实性、材料完整度、陈述审核状态是三个独立维度。网页摘要经人工确认也仍只是那段摘要，不能因此改称论文全文。

## 前置缺口与后置缺口

M01/M02 已有统一候选池、学术/网页类型筛选、arXiv 自动取全文、本地上传与材料完整度。N12 进一步补齐材料快照、当前检索隔离、历史分析/引用保留。非 arXiv 自动取全文、普通网页正文抓取与更复杂的跨来源附件关联仍未完成。

M03 已接通全部提取后、复核前独立持久化候选，跳过或失败后可直接人工确认/撤销；机器能力感知批量已接通，不再统一描述为逐条小片段。提取中途的逐指令保存与复杂来源质量仍有边界。N05/N06 人工补录和质量面板已接通，统计为已采集漏提占比，不是真实召回率。

当前模块能力和验收范围统一见[状态页](../当前实现与验收状态.md)，后续只看[实施计划](../实现计划.md)。N04严格范围4轮、默认联网与真实追问2轮小样本主要目标已满足，默认概述/比较范围及扩展字段类型均已离线收口；当前整理提交，不增加功能。N08/N12、N09本机集成和N10限定范围已验，真实Electron/安装生命周期仍留N11。F3/embedding暂停，原始失败不回写。
