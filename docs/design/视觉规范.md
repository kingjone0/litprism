# 视觉规范

更新：2026-10-28。本文是**界面视觉的唯一权威**：设计令牌、布局尺寸、组件写法与禁用模式。
产品行为、能力边界与验收状态不在这里，见[当前实现与验收状态](../当前实现与验收状态.md)；
执行顺序见[实现计划](../实现计划.md)。令牌的源码位置是
[`app.css`](../../src/litprism/web/static/app.css) 的 `:root` 与 `[data-theme="dark"]`，
本文与源码不一致时以源码为准并立即修本文。

## 为什么需要这份文档

2026-10-28 接入一份外部"前端优化包"时，同一批改动引入了两类可避免的缺陷：
5 处 >1px 彩色左边框（与既有层级语言冲突）、主按钮 hover 时文字对比度降到 1.9:1。
两者都不是审美分歧，而是缺少可对照的约束。本页把已确定的规则写死，
使后续改动（无论人或工具产出）能在提交前自查，而不是靠事后检测器发现。

## 设计取向

现代学术研究工作台：暖纸张中性底 + 深林绿主色，长时间深度阅读不刺眼。
浅色为默认，`data-theme="dark"` 切换。不使用渐变文字、玻璃拟态或高饱和强调色。

## 令牌

### 颜色（浅色 / 深色）

| 令牌 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `--bg` | `#f8f7f4` | `#141413` | 页面底色 |
| `--panel` | `#ffffff` | `#1c1c1a` | 卡片、输入框等浮起面 |
| `--panel-2` | `#f1f0ec` | `#242421` | 次级面（折叠头、代码块底） |
| `--panel-3` | `#e8e6e0` | `#2c2b28` | 三级面（hover 底、禁用态） |
| `--border` | `#e4e1da` | `#302f2b` | 常规分隔线 |
| `--border-strong` | `#d1cdc4` | `#43413b` | 需要明确边界的容器 |
| `--text` | `#1c1b18` | `#f0ede8` | 正文与标题 |
| `--text-2` | `#4a4640` | `#c7c2b8` | 次级正文、说明 |
| `--muted` | `#68635c` | `#a39e95` | 元信息、占位符 |
| `--accent` | `#236347` | `#5ec293` | 主色：主按钮底、选中文字 |
| `--accent-hover` | `#1c523a` | `#4eb082` | 主按钮 hover 底 |
| `--accent-soft` | `#e6f2ec` | `#1b3328` | 选中底、引用块底 |
| `--accent-line` | `#b3d4c3` | `#2d5944` | 主色系描边 |

语义色成对使用（`--x` 配 `--x-soft`）：`ok` 与主色同值，另有 `manual`（人工）、
`warn`（提示）、`danger`（危险/拒绝）、`neutral`（中性）。

### 对比度（实测值，AA 要求正文 ≥4.5:1）

| 组合 | 浅色 | 深色 |
|---|---|---|
| `--text` / `--bg` | 16.08 | 15.79 |
| `--text-2` / `--bg` | 8.75 | 10.39 |
| `--muted` / `--bg` | 5.56 | 6.92 |
| `--muted` / `--panel-2` | 5.22 | 5.84 |
| `--accent` / `--accent-soft` | 6.20 | 6.20 |
| 主按钮文字 / `--accent` | 7.13（白） | 8.36（`#0e1712`） |
| 主按钮文字 / `--accent-hover` | 9.06（白） | 6.83（`#0e1712`） |

新增或调整颜色时必须重算这些组合。`--muted` 在浅色底上曾为 `#86807a`（3.9:1，不达标），
已提升到 `#68635c`；不要为了"更轻"再调回去。

### 圆角、阴影与尺寸

| 令牌 | 值 | 用途 |
|---|---|---|
| `--radius-lg` | 14px | 大容器、模态框 |
| `--radius` | 12px | 卡片 |
| `--radius-sm` | 8px | 按钮、列表项、折叠头 |
| `--radius-xs` | 6px | 标签、引用块、小控件 |
| `--shadow-xs` | 极轻 | 按钮、输入框 |
| `--shadow-1` | 轻 | 常规卡片 |
| `--shadow-2` | 中 | 浮层、侧栏抽屉 |
| `--shadow-3` | 重 | 模态框 |
| `--sidebar-w` | 232px | 左侧栏 |
| `--inspector-w` | 352px | 右栏（证据与详情） |
| `--titlebar-h` | 44px | 顶栏 |
| `--tabbar-h` | 42px | 标签栏、右栏标题行 |

字体栈 `--sans` 优先系统字体，`--mono` 用于代码与数据，`--serif` 用于长文阅读区。
不引入远程字体文件。

## 组件写法

| 组件 | 约定 |
|---|---|
| 主按钮 | `--accent` 底 + 白字（深色主题 `#0e1712`）；hover 用 `--accent-hover`，**必须重申文字色** |
| 次按钮 | `--panel` 底 + `--border` 描边；hover 换 `--panel-2` 底 + `--muted` 描边 |
| 危险操作 | `--danger` 文字与描边，hover 用 `--danger-soft` 底；不与主按钮同权重并排 |
| 卡片 | `--panel` 底 + `1px --border` + `--radius`；卡片内不再套卡片 |
| 折叠头 | 自绘 chevron（`::before` 三角 + `[open]` 旋转 90°），不用原生 `summary` 标记 |
| 空状态 | `emptyState()`：图标方块 + 标题 + 一句说明 + 可选动作；已在卡片内时用 `bare` |
| 解读状态条 | 阻断一条（`data-level="block"`）+ 其余折叠；只有提示时整行收起（`data-level="notice"`） |
| callout | `1px` 整圈描边 + 底色；变体只改 `border-color` 与 `background` |
| 引用块 | `--accent-soft` 底 + `1px --accent-line` 描边，不用单侧粗边 |

## 禁用模式

以下每一条都对应一次真实缺陷，不是风格偏好。

| 禁用 | 原因 | 替代 |
|---|---|---|
| `>1px` 的彩色 `border-left/right` | 与圆角容器脱节，读成"旁边多一条线"而非容器边缘；2026-10-28 优化包引入 5 处 | 整圈 `1px` 描边 + 底色；侧栏选中态用底色 + 字重 + 图标实心度 |
| hover 只改背景不改文字色 | 被更具体的 `:hover` 规则改掉 `color`，深色底上出现近黑文字（实测 1.9:1） | hover 规则里重申 `color` |
| 原生 `<summary>` 三角 | 画在内容盒外侧，父级内边距 12–14px 时压住边框 | 自绘 chevron |
| Unicode 字形 / emoji 当图标 | 字重与基线不受控，跨平台不一致 | 本地 SVG（`icon()`，统一 1.6 描边） |
| 标题上方压 eyebrow / kicker | 与标题争夺层级，标题本身已承载含义 | 让标题直接说话 |
| 固定 `height` + 纵向 0 内边距 | 文字贴住容器上下边 | `min-height` + 纵向内边距 |
| 小于 11px 的功能文字 | 可读性不足 | 正文 ≥12px，控件文字 ≥11px |
| 窄屏可点区域小于 44px | 触控误触 | `min-block-size: 44px`（已有 `.chat-live-draft .btn` 先例） |

## 自查方式

改完界面文件后运行机械检测（无自动 hook 时手动执行）：

```bash
"$HOME/.workbuddy-ai/skills/impeccable/scripts/impeccable.cmd" detect --json \
  src/litprism/web/static/app.css \
  src/litprism/web/static/lit-ui.css \
  src/litprism/web/static/index.html
```

空数组 `[]` 为通过。`index.legacy.html` 的 11 条提醒是既有历史模板，不在本规范治理范围，
也不作为重设计理由。

视觉改动必须同时查看**浅色与深色**两种主题，窄屏改动另看 390px。
截图工具见 [`tools/_shot.js`](../../tools/_shot.js)（巡览 9 个页面与右栏，共 17 张）。

## 边界

- 本页只管视觉层；交互契约见[证据交互契约](../证据交互契约.md)，模块行为见[六模块](../modules/README.md)。
- 规范不承诺无障碍认证：对比度是计算值，真实读屏、缩放与硬件性能未验收。
- 检测器通过不等于设计正确；它拦的是已知反模式，不判断信息层级是否合理。
