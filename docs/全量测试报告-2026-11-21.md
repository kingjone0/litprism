## 发现清单

| # | 级别 | 发现 | 处置 |
|---|---|---|---|
| 1 | P3 | **chat run `/events` 偶发 404**：mock 非流式 run 在特定时序（发送后立即连接）下 events 端点返回 404（`row(rid)` 未命中），事后同 rid curl 200。功能不受影响（回答正常渲染），console 报错噪音 | 登记待查：events 与 run 创建的事务可见性时序 |
| 2 | P3 | **G07 附件无 UI 取回入口**：附件经 API 可取回（本走查 PASS），但论文详情页材料区域未提供「下载原件」按钮——能力完整、入口缺失 | 登记条件项：UI 取回按钮（小改动，随下一批） |
| 3 | P3 | **标注计数跨 tab 的刷新依赖**：在原文 tab 保存标注后，详情页 tab 计数经 `refreshAnnotations` 异步刷新（本次实测正常），但硬编码计数的自动化断言会误报 | 已修走查脚本为增量断言；产品无改动 |
| 4 | 信息 | mock provider 对真实长文不产出候选（启发式不命中），解读闸门诚实显示"12 段未通过/未提取陈述" | mock 行为符合设计 |
| 5 | 信息 | `deepseek-v4.1-flash` 为思考模型：短问答回复可能先耗 reasoning tokens（短测 16 token 全为思考） | 无需处理 |
| 6 | 信息 | 旧 provider 密钥失效根因：`user_5...` key 可读目录但推理 401（服务端策略），已由新 `user_2...` key 替换并验证 | 已解决（仅测试副本接线，日常库未动） |
