## 本机已验（2026-11-20 真实库演练）

`python tools/backup_drill.py --home <真实数据根> --execute`：对真实库做只读在线快照并恢复到全新演练目录，逐表行数/逻辑 sha256/文件树 sha256 与源一致、迁移幂等 0、绝不激活。报告与逐表清单留在 `_selftest.g08-drill-*/drill-report.json`。执行要点：

- 源库全程只读 URI 打开；LitPrism 应用可保持运行（在线 backup API 含 WAL 已提交内容）；
- 若报告 `snapshot_error` 为 schema 版本不一致，说明真实库尚未运行过当前版本应用，先启动一次新版本完成迁移再演练；
- 演练不替代"激活切换"：切换仍是显式人工操作（恢复 → 预检 → 安排重启切换）。

## 真实环境未验（按需求逐项安排，不自动开工）

| 项 | 需要什么 | 核对方法 |
|---|---|---|
| 真实多屏/显示器热插拔 | ≥2 物理显示器 | 窗口跨屏拖动、断开/重接显示器、DPI 缩放变化后检查 `window-state.json` 恢复是否落在可见工作区（逻辑已在 31 项 Node 模拟覆盖） |
| 真实 GPU 渲染 | 非虚拟化显卡 | 应用当前禁用 GPU（Electron `disable-gpu`，规避 Chromium `0xC0000005`）；若未来启用 GPU 需重验全界面渲染与窗口截图 |
| 杀软共存 | 真实第三方杀软 | 安装包安装/卸载、sidecar 启动、备份导出是否被拦截；保留杀软日志与放行记录 |
| 跨机/跨用户恢复 + 密钥重配 | 第二台机器，或本机第二个 Windows 账户 | ①备份导出（不含密钥）②新账户/机器上恢复到新目录 ③启动后确认缺密钥报错而非退 mock ④重新配置 Key 后功能可用（DPAPI 密文绑定机器+用户，属预期行为） |
| 无 Python 环境运行 | 干净机器或全新 CI 镜像 | 安装包安装后启动；sidecar 为 PyInstaller 自带运行时，云端已证明路径内无 python（该项已基本由 CI 覆盖，剩余差异极小） |
