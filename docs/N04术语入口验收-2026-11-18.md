# N04 术语入口限定验收

2026-11-18。结论：论文详情能读出术语并继续到严格限定该论文的新对话。固定样本的主要概念和论文用法可读；术语直接回源、缺证区分及同全文重复提取有明确缺口，本轮不判整体通过。

## 固定样本与边界

- 沿用已冻结的公开论文 *Attention Is All You Need*（43块）和 *BERT*（75块），用各自的完整当前原文生成与生产一致的 `concepts` 请求。核对原来源清单哈希及隔离副本当前块。DeepSeek V4.1 Flash 每篇一次首次请求，无自动补跑、无联网搜索、无新增六字段提取、QA 或模型复核。未读写日常库。
- 用两份原始响应原样离线走生产解读中的术语过滤和保存，通过真实本地 API、Chrome 和隔离数据库读回。其他解读阶段是离线桩，不是新论文解读的验收。另用同一材料跑负例和空术语列表。
- 当前入口是「论文详情 → 术语」，该页只展示选中论文的提取结果；没有独立的跨论文术语比较。下面的跨论文比较由本次验收逐篇核对，未把它算成应用自动比较。

## 内容核对

两次首次请求均成功；Transformer 14 条、BERT 15 条均通过现有引用检查并入术语表。编号和物理页都能对应保存时的原文。29 条是结构放行数量，不是语义通过率。以下固定重点检查论文定义、实际用法、同族概念差异与缺证边界；各篇 `P#` 仅在该篇分析中有效。

| 核对项 | 首次响应与原文对照 |
|---|---|
| Attention / scaled dot-product attention | Transformer P13–P15，物理页3–4，支持查询、键、值及基于兼容度的加权；缩放、softmax 和矩阵式均有直接依据。 |

## 路径验收与缺口

| 区域 | 实测结果 |
|---|---|
| 进入术语、回到研究 | 从知识库打开两篇论文，各自正确呈现术语数量；从「术语」点「就这篇提问」，两次均创建只含该论文的严格范围会话，原有对话不改。验证的是范围传递，没有再发聊天模型请求。 |
| 原文回查 | API 中的术语引用能对上具体原文块和页码；Chrome 手动切「原文」可看到对应内容。但术语行只是纯文本，不能点引文定位或在右栏打开。 |
| 缺证与错误引用 | 无引用、错页和不存在的 P 编号均被过滤；查找不存在的术语返回空。合成负例「真实页码 + 同页未出现的术语/公式」却仍进入术语表。引用存在只说明能回查；通用解释、单纯提及、论文定义及内容不支持，产品没有单独标记。空表只显示「暂无术语」。 |
| 调用组织 | 离线回放捕获同一论文的逐字相同术语请求：Transformer 两次、BERT 四次。原因是 `concepts` 在六字段指令循环里执行，整篇模式每次复用同一全文和术语提示；持久调用记录只对相同历史步骤复用，不在不同新步骤间去重。此次线上严格只发两次，不能把离线重复计入用量。 |
| 可读性 | 两篇各通过 1360 / 390 px × 明暗主题，共 8 组；无整页横向溢出、控制台错误或外部浏览器请求。390 px 使用固定较宽术语列，正文较窄且断行频繁，适合改为单列条目。 |

## 修复与离线复验

以上是首次验收结果，原始响应和用量未改。修复后的术语表使用分析自己的材料版本、块 ID 和物理页打开同一证据右栏；材料换版只改变新的分析来源。链接可以用键盘打开，从右栏返回时回到原链接。窄屏把术语和释义改为单列。

新生成格式分为「论文定义」「文中用法」「通用含义」「证据不足」。论文内的定义和用法必须有实际发送片段的有效引用、可定位原句和术语写法；通过定位只显示「释义未审核」。无法定位的主要释义折叠为待核对，通用含义不挂论文引文。已有单段释义不回写：只拆明确写出的「通用含义」，其余保留为论文语境或明示的文中用法，并显示「释义待核对」；原始 BPE 范围问题仍保留在首次记录。引用过关不能排除真实原句被错误解释，也不授予可信知识状态。

两份原始响应按同一原文前缀离线回放后仍为 14/15 条；原来提出 2/4 个相同请求的同全文路径现在各尝试一次，失败不在后续全文指令中重复尝试。实际分批仍按不同原文分别提取。旧未完成解读的调用顺序与新版本不同，继续沿版本绑定保留原记录并拒绝不兼容续跑；新版本自己的持久运行与显式重试路径保留。假术语 + 有效页码显示「证据不足」，原释义折叠；错误页码、缺引用及不存在的编号仍被过滤。

两篇 Chrome 离线回放覆盖 1360/390 px × 明暗主题、键盘回源/返回、窄屏侧栏和严格单篇对话；独立控制另验「证据不足」的折叠和空列表。原始证据哈希保持，无新模型、搜索或外部浏览器请求。新格式受离线正反控制验证，尚未用真实模型重新生成，不能以此声称 BPE 首次响应中的范围错误已自动纠正。新复验文件位于 `_selftest.n04-terms-fix-20261118/`。

全套 pytest 1584 项及完整离线工作流通过；最终证据守卫和持久运行相关 65 项回归通过，均为同一个既有第三方弃用警告。下一步在原 BPE 反例论文上做一次固定的真实新格式生成，检查英德/英法范围和分栏，不扩大样本或增加全量模型复核。

## 新格式首次真实验收

固定同一 Transformer 论文的 43 块当前公开原文，使用产品的完整术语提示词，只调用一次 DeepSeek V4.1 Flash；未加入 BPE 专项提示，没有补跑、联网搜索、六字段生成或模型复核。首次请求成功，耗时 58.605 秒，服务报告 16,399 token（9,224 输入；7,175 输出，其中 3,398 为思考；缓存输入 0）。前两篇的首次产物哈希、用量和评估仍原样保留。

本次以语义、归属和主要条件为标准，接受忠实转述、合理的背景补充和小幅范围扩展。**BPE 范围反例在模型响应上通过**：BPE 词条明确把约 37,000 的共享词表限定于 WMT 2014 英德数据；数据集词条另外记录英法的 32,000 word-piece 词表，两者均可在 P30（物理页 7）核对。应用未修写原始响应。BLEU 词条把论文用法、通用含义和公式缺证分开，同时如实保留摘要与第 6.1 节的英法 BLEU 不一致（分别 41.8 和 41.0，P2/P34），没有把两处数字合成一个结论。固定单篇不用于推断总体语义质量。

用首响离线回放生产解读路径，确认实际发送提示词与生产一致、同全文只调用一次、14 条术语均可在页面读回。模型生成 8 条定义、20 条用法、1 条通用含义、4 条主动缺证；应用显示 7 条定义、14 条用法、1 条通用含义、11 条缺证。新增的 7 条来自程序降级，不能当成模型语义错误或真实无证据：

| 降级原因 | 首次结果中的具体表现 |
|---|---|
| 4 条未复现完整术语名 | 缩放点积注意力的公式/动机、FFN 的 512/2048、英法模型的 dropout 设置、句法分析的 beam 参数。引用落在参数或续写片段，术语的完整称呼未在每个用法引用里复现。 |
| 3 条未精确匹配单块引句 | BPE 的原文索引把 `source-target` 连成 `sourcetarget`（P30），正确的主要释义因此被折叠；位置编码定义的引句跨 P23/P24；BLEU 变体引句实际上在 P36，模型引用的是后续 P37/P38。后两例需要明确显示补充块，不能静默替换模型引文。 |

Chrome 以原样首响检查术语表、通用含义无论文链接、7 条降级可查看原释义；键盘实际打开 BPE、BLEU、Transformer 的保存版本原文并返回。1360/390 px、明暗主题共 4 组检查通过，无整页溢出、控制台异常或外部浏览器请求。界面回放无模型调用。没有修改生产代码、日常库或提交。
