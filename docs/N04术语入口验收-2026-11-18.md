# N04 术语入口限定验收

2026-11-18。结论：论文详情能读出术语并继续到严格限定该论文的新对话。固定样本的主要概念和论文用法可读；术语直接回源、缺证区分及同全文重复提取有明确缺口，本轮不判整体通过。

## 固定样本与边界

- 沿用已冻结的公开论文 *Attention Is All You Need*（43块）和 *BERT*（75块），用各自的完整当前原文生成与生产一致的 `concepts` 请求。核对原来源清单哈希及隔离副本当前块。DeepSeek V4.1 Flash 每篇一次首次请求，无自动补跑、无联网搜索、无新增六字段提取、QA 或模型复核。未读写日常库。
- 用两份原始响应原样离线走生产解读中的术语过滤和保存，通过真实本地 API、Chrome 和隔离数据库读回。其他解读阶段是离线桩，不是新论文解读的验收。另用同一材料跑负例和空术语列表。
- 当前入口是「论文详情 → 术语」，该页只展示选中论文的提取结果；没有独立的跨论文术语比较。下面的跨论文比较由本次验收逐篇核对，未把它算成应用自动比较。

## 内容核对

两次首次请求均成功；Transformer 14 条、BERT 15 条均通过现有引用检查并入术语表。编号和物理页都能对应保存时的原文。29 条是结构放行数量，不是语义通过率。以下固定重点检查论文定义、实际用法、同族概念差异与缺证边界；各篇 `P#` 仅在该篇分析中有效。

| 核对项 | 首次响应与原文对照 |
|---|---|
| Attention / scaled dot-product attention | Transformer P13–P15，物理页3–4，支持查询、键、值及基于兼容度的加权；缩放、softmax 和矩阵式均有直接依据。 |
| Transformer 架构 vs BERT 中的 Transformer encoder | Transformer P9–P10，物理页2，给出编码器—解码器及自回归生成；BERT P16，物理页3，明确采用多层双向 Transformer 编码器。两页保留各自论文语境，没有把完整架构与编码器等同；需逐篇查看。 |
| BERT 的 MLM / NSP | MLM 目标对应 P5–P7、P21；P22 进一步区分选中 15% 预测位置与具体 80/10/10 替换策略。「随机掩码15%」沿用原文简写，适合概览；用于复现时应写成「选取15%的位置作预测」。NSP 的真实下一句与随机句各半对应 P23，向量 C 的用途对应 P24。 |
| BERT 的分类和分隔符 | P13、P18–P19 支持 `[CLS]` 的序列聚合作用与 `[SEP]` 的分隔作用；P24 支持 `[CLS]` 向量用于 NSP。 |
| BLEU / WordPiece：文中用法与通用含义 | BLEU 的 WMT 2014 英德 28.4 有 Transformer P2 支持；BERT 的三万词表、掩码单位有本篇 P18/P21 支持。响应已用文字标记「通用含义」，但同一单元格、同一引用样式容易被误读为通用解释也有论文背书。 |
| BPE：范围反例 | Transformer 的术语解释将「编码句子、共享约37,000 token词表」泛写为论文的用法。P30同页接着说明英法数据使用约32,000的 word-piece 词表。应把 BPE 和 37,000 限定到英德数据，这条仍被现有闸门接受。 |

## 路径验收与缺口

| 区域 | 实测结果 |
|---|---|
| 进入术语、回到研究 | 从知识库打开两篇论文，各自正确呈现术语数量；从「术语」点「就这篇提问」，两次均创建只含该论文的严格范围会话，原有对话不改。验证的是范围传递，没有再发聊天模型请求。 |
| 原文回查 | API 中的术语引用能对上具体原文块和页码；Chrome 手动切「原文」可看到对应内容。但术语行只是纯文本，不能点引文定位或在右栏打开。 |
| 缺证与错误引用 | 无引用、错页和不存在的 P 编号均被过滤；查找不存在的术语返回空。合成负例「真实页码 + 同页未出现的术语/公式」却仍进入术语表。引用存在只说明能回查；通用解释、单纯提及、论文定义及内容不支持，产品没有单独标记。空表只显示「暂无术语」。 |
| 调用组织 | 离线回放捕获同一论文的逐字相同术语请求：Transformer 两次、BERT 四次。原因是 `concepts` 在六字段指令循环里执行，整篇模式每次复用同一全文和术语提示；持久调用记录只对相同历史步骤复用，不在不同新步骤间去重。此次线上严格只发两次，不能把离线重复计入用量。 |
| 可读性 | 两篇各通过 1360 / 390 px × 明暗主题，共 8 组；无整页横向溢出、控制台错误或外部浏览器请求。390 px 使用固定较宽术语列，正文较窄且断行频繁，适合改为单列条目。 |

首调用耗时 43.321 秒 / 53.908 秒。服务共报 **36,477 token**（输入 26,891；输出 9,586，含思考 6,992），未报告缓存输入，货币金额未知。相关 pytest **91 项通过**，有一个既有第三方弃用警告。首次浏览器脚本把会话列表序列化的 `scope` 当对象读，原断言日志保留；改为按接口解码后，实际首次模型结果无需重跑即可走完全程。
