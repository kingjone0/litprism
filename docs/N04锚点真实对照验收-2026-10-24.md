# N04 原句与锚点真实对照验收

## 目的与固定范围

本轮验证模型实际选择原文锚点的效果，比较现役严格原句协议和默认关闭的 `qa.evidence_anchor_trial`。不扩大日常聊天、不更换模型、不新增论文或解读，不增加本地 embedding；也不以位置有效认证语义正确。

用户已要求执行验证，沿用此前“按固定验收完成”的预算方式。原计划冻结六个问题，每题两种协议，各一次首次请求，估算最多十二次真实模型调用；实际另有两次查询扩展，漏计偏差见执行结果，原计划不回写。输出按现有模型能力自动分配，无新增手工 token 上限。连续三次服务失败停止；失败不重发、不补跑挑结果。观察等待结束不代表可以重发请求。

| 题目 | 核对重点 |
|---|---|
| v1 | Transformer 基本架构及 PDF 连字符原句 |
| p1 | 本地 Transformer 与本轮网页摘要分别引用 |
| a1 | BERT 摘要缺失训练参数，不套用 Transformer 全文 |
| x1 | Transformer/BERT 架构、训练目标与主要任务的对象归属 |
| x2 | BERT/RAG 参数化表示与外部检索记忆的直接来源 |
| s2 | 空选择允许相关本地检索和已开启的外部摘要 |

题目冻结在 `tools/anchor_live_cases.json`；工具为 `tools/anchor_live_acceptance.py`。通过新持久 Web 入口执行，每个问题使用独立会话，两组从同一个场景数据库复制，网页来源 ID、块 ID、文本、可信状态和材料版本相同，交替执行协议顺序。请求级授权 ID 和获取时间自然不同，题目不比较获取日期；内容与逐来源顺序另外校验。不把历史对话作为事实输入。

原论文来自已有隔离验收根；网页为此前实际获取、已冻结并校验哈希的 arXiv 摘要，在搜索边界回放。不是新的 Tavily 在线搜索验收，不据此宣称搜索服务与模型整链路通过。待审摘要只按本轮授权引用，不自动入可信库。

## 判定方式

分别记录服务完成、实际送达材料一致性、引用编号/快照/物理页解析、引句或锚点定位、陈述对象与语义支持，以及人工核对负担。原始请求、持久化结构化响应、调用设置和未知用量仅保存在本地 `_selftest.n04-anchor-live-20261024/`；未另存提供商 HTTP 原始响应字节，旧验收结果不改写。固定的真实 P77 错绑等反例仍由既有离线控制保留。

语义由开发代理对照原文逐条审查，未增加独立真人标注：关键结论错误、错对象或直接来源不能支持结论判失败；来源不足但清楚限定、没有编造，单独记为合理保留或待核。定位有效不能抵消语义错误，正常发布也不等于验收通过。这些审查不是用户确认入库。

人工成本先记录每条回填字符数、定位粒度和核对操作，字符数只作工作量代理；未进行真人计时研究，不宣称减少了多少审核时间。缺映射和服务失败保留未知，不能作为零定位错误计入成功分母。单次小样本只作方向性判断，不估计总体成功率或显著性。

## 执行与结果

执行前完整回归：1248 项通过，1 个第三方弃用警告，无 skipped。新增验收工具的同源对照、失败保留与不重发检查通过，执行时版本的完整回归为1252项。真实执行的工具和题目已另外冻结在本地 `executed-tool.py` / `executed-cases.json`，哈希与原manifest一致；下述结果不随后续工具修正回写。

十二条回答均完成，无服务失败、无未知用量、无重发。实际模型调用为 **14次：12次qa + 2次expand**，共271,642输入、75,375输出、347,017已知token。原计划“最多十二次”漏计空选择检索的查询扩展，是本轮验收计划偏差，不能改称原计划已准确执行。每个任务的请求设置均为attempts=1；原工具以“一条回答只有一次模型调用”判断first_attempt_only，错误标记了s2两个不同任务的首次调用。原始标记保留，另在 `development-review.json` 按任务与尝试记录对账。随后仅离线修正工具预算口径并加入发送前任务次数守卫，未追加真实请求。

实际qa请求均采用自动输出，1,000,000上下文、384,000最大输出、900秒等待；没有重新设置小输出窗口，也没有输出截断。213/213实际引用编号、冻结来源及显式物理页校验通过，这只是解析/回溯通过，不能当作语义通过。

## 结论与下一步

**整体未通过，不扩大锚点默认使用。** 观察到定位改善，但集合/条件归属仍可在位置有效时出错，且大量claim仍是对回答的再概括；较粗的段落/整块锚点增加了展示文字。编码代理对照原文的审查不是独立真人标注，也不是自动语义认证。

下一步先补两个具体环节：让陈述记录准确对应已展示回答的句子，并把原文锚点细化为可核对的短句/短段范围，保留跨句多证据和原始字符。随后用本轮原响应零调用复现、误拦检查及右栏工作流验收，再决定是否需要新的固定真实对照；不预先增加整轮模型复核。未来对照须单独冻结/复用查询扩展结果，或明确按非配对样本报告，预算须包含expand。数值通用对齐、撤稿/更正、长会话和N09继续按原优先级等待。

验收工具修正后完整回归 **1254项通过**（本轮开始1248，新增6条），1个第三方弃用警告，无skipped。本轮未改产品源码或UI、未迁移日常库、未提交；未重新运行可见窗口或打包。既有产品无窗口UI验收仍作为交互证据，真实持久Web调用与结构化结果单独保存。
