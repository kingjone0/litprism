# 证据链与优先缺口补齐 · 2026-10-18

本轮从 `11ab22f` 开始。按用户后续要求放慢扩展节奏，先把“回复来源链接 → 右栏原文 → 可信状态 → 人工确认加入”做成可验证的链路。F3 继续暂停；本轮源码尚未提交、未打包。

## 已实现并验证的证据交互

1. **回复后来源链接**：从实际使用的引用及数据库来源生成；点击后右栏显示原文片段、来源类型、标题、URL/DOI、页码和当前可信状态。普通回复不再展开整张引用列表。历史链接按稳定 ID 回到原来源，不使用当前轮 P 编号猜测。
2. **论文、知识、网页分开标识**：论文沿用五态核验；知识与网页存为独立快照。非论文来源不能冒充自动核验的论文，也不进入偏好记忆层。
3. **右栏人工审核**：待审核来源不能作为 QA 的事实证据；用户检查快照、填写依据后确认加入。审核绑定内容哈希、记录时间和动作；支持拒绝及撤销。撤销后停止检索，下载重新校验失败，旧回复链接仍可查看并显示当前失效状态。
4. **生成期间状态复核**：调用模型后再次检查实际来源；若这期间被撤销或回收，不展示基于它的结论。不是只在请求开始时查一次。
5. **网页候选入口**：可粘贴网页片段和 URL，也可显式搜索 Tavily 摘要候选。对话中“同时搜索网页候选”默认不勾选；结果作为独立待审链接附在回复后，不直接送入模型的事实证据。未配置服务时明确提示，不生成假来源。

网页适配依据 [Tavily Search 官方接口](https://docs.tavily.com/documentation/api-reference/endpoint/search)，只保存返回的摘要快照，默认不抓取任意 URL。联网适配本轮使用服务桩验证，未做真实 Tavily 服务验收，不等于 W1–W3 全部完成。

状态与字段规则详见 [证据交互契约](证据交互契约.md)。人工确认代表用户接受该快照，不代表客观事实已被自动证明。

## UI 验收发现并修复的问题

- 切换会话时先移除旧输入框，再等待新会话；防止输入在旧 DOM 与异步新内容之间丢失。
- 侧栏按请求序号忽略旧响应，防止旧详情覆盖新审核状态。
- 任务取消控件在 Skill 原生 dialog 的顶层内显示；关闭 dialog 后任务条转移到页面，避免取消按钮被遮挡。
- 新增会话管理按钮保持行内，不把侧边栏撑成两行；来源时间按浏览器本地时间展示。
- 网页原文与标题按文本转义；不执行或渲染候选中的 HTML。

## 验收边界与下一步

“全部原文已送入模型”是请求覆盖事实，不证明模型理解了每一段。现有检查验证出处、编号、页码、范围和状态，不能替代逐句语义核对。知识检索当前为词法检索，规模和跨语言效果还需专门评估。

下一步先用真实长论文核对章节覆盖、表格/公式、多批结论一致性及引用语义；再验证真实网页搜索服务和长会话。备份、自动回取及其他集成继续单独推进，不赶 F3。本轮未再次调用付费模型，也未修改用户现有知识库或密钥。
