### F0 · sidecar 握手与 token 防护 —— ✅ 完成

| 文件 | 内容 |
|---|---|
| `src/litprism/sidecar.py` | Tauri sidecar 入口：握手协议 + token 中间件 |

**握手协议**：外壳以子进程启动 sidecar → stdout 打一行
`LITPRISM_READY {"port":…, "token":…}` → 外壳读行、把 token 经 IPC 注入前端 →
前端所有 /api 请求带 `X-LitPrism-Token` 头。

**为什么需要 token**：端口在 127.0.0.1 上，本机其他进程同样能访问。
一次性 token 保证只有经外壳启动的前端能用 —— 本地单机应用的最小访问控制。

**实测**（200/401/401，静态资源不设防）：

```
带 token      → 200
错误 token    → 401
无 token      → 401
静态资源      → 200（不设防，前端加载需要）
```

#### spike 抓出的真实缺陷：frozen 下所有路径落到 `%TEMP%`

**现象**：`/api/status` 的 `db_path` = `C:\Users\...\AppData\Local\Temp\data\litprism.db`。

**根因**：`PROJECT_ROOT = Path(__file__).resolve().parents[2]`。onefile 模式下 `__file__` 在
`_MEIPASS`（临时解包目录），于是 `./data` 与 `config/` 全部解析到临时目录 ——
用户装好用一周，数据可能被系统清理。连带 `config/` 未进 `datas`，用户配置生成不出来。

**修法**：拆成两个根，并抽纯函数便于测试：

| 根 | 源码 | frozen | 用途 |
|---|---|---|---|
| `BUNDLE_ROOT` | 项目根 | `sys._MEIPASS` | 只读资源（配置模板、static） |
| `APP_ROOT` | 项目根 | `%LOCALAPPDATA%\LitPrism` / `LITPRISM_HOME` | 可写（data、用户配置、密钥库） |

**验收（实测）**：db_path 落 `%LOCALAPPDATA%\LitPrism\data\`；用户配置生成于该目录；`GET /` 200、`/api` 无 token 401；**重启后 papers=1 chunks=61 仍在**。

**顺手修的两处**：握手行的 `pid` 原先写死 `null`，改为真实 PID；token 守卫只守 `/api`
（token 保护的是**数据**，不是界面外壳 —— 挡住 `/` 既不增加安全，又让打包版无法在浏览器排障）。

**新增测试** `tests/test_paths.py`（10 项）：模板只读、用户配置可写、`LITPRISM_HOME` 优先、
已存在的用户配置不被模板覆盖。全量 **506 项通过**。

### F2 · 外壳工程 —— ✅ 完成（选定 Electron）

**结论**：外壳用 `desktop-electron/main.js`。Tauri 工程保留在 `src-tauri/` 作备选，
但当前环境跑不起来 —— **根因是这台机器 Chromium 的 GPU 进程以 `0xC0000005` 崩溃**
（`FATAL: GPU process isn't usable`），Tauri 的 WebView2 与 Electron 同一底座，都白屏。
Electron 加 `--disable-gpu/--disable-gpu-compositing/--disable-gpu-sandbox/--no-sandbox`
后正常渲染。

**F2 交付**：
| 项 | 结果 |
|---|---|
| 窗口渲染 | ✅ 实测截图 + DOM 自证：侧栏/知识库/检视面板齐全 |
| 数据加载 | ✅ 真实数据（BERT、61 块），脚本来自 `127.0.0.1:<port>/static/*` |
| token 传递 | ✅ URL hash（`#t=`），页面读到 |
| 单实例 | ✅ `requestSingleInstanceLock` |
| 进程回收 | ✅ 关窗后 sidecar 零残留（先用握手 pid 杀，再收启动器） |

**两个实现坑**：`spawn` 不能直接跑 `.bat`（EINVAL，需 `cmd /c`）；
先杀 onefile 启动器会让真进程成孤儿（要先杀握手 pid）。

**方法学**：判定"有没有渲染"不能靠拍屏幕（会被上层窗口遮挡，走过好几轮冤枉路）；
改用 Electron 的 `capturePage()` + `executeJavaScript` 把证据写到文件。
判定"是不是我们的页面有问题"用最小页（`PROBE-OK`）替换，一次就能切开。

**未验证**：加上 `--disable-gpu` 类参数后 Tauri 是否可用 —— 不要据此断言 Tauri 不可用。
