# 相邻证据补足与拆段丢失修复

2026-10-18（第二轮）。承接 [有界复核与短论文实测](有界复核与短论文实测-2026-10-18.md) 末尾
「自动复核需要继续改善相邻证据的完整性」。本轮**只动证据装配层**，不改判定标准、不放宽护栏。

## 发现的两个真实缺陷

### 1. 同一 chunk 被预算拆段时，前半段在复核里凭空消失

`reading_batches`（`src/litprism/reading.py`）在上下文预算不足时，会把**一个 chunk 拆成多段**，
但**沿用同一个 tag**（`dict(item, text=remaining[:lo])`）。

而 `semantics.py` 里所有按 tag 建索引的地方都是 `{e['tag']: e for e in excerpts}` —— 后段覆盖前段。
后果：

- 送进模型 `sources` 的只有**最后一段**，表格前半、段落开头不在提示词里；
- `_quotes` 的逐字核验也只对着最后一段做，引用前半段的判定必然匹配失败。

这正是实录里那条「p.4 表格中途截断，后续片段补齐了另一个隐藏层设置」被机器判成**不符**的机制：
模型没看到前半张表，不是看错了。

修法：`merge_fragments()` 把同 tag 的多段按原顺序拼回一条。片段本身就是原文的连续子串
（`remaining[:lo]` / `remaining[lo:]`），直接拼接**不引入任何新文字**，可逐字核验。

### 2. 拆段会产生重复 tag 的引用清单，导致导出硬失败

`extract.py` 与 `agents.py` 都用 `all_excerpts` 逐条构造 `_citations`。拆段后同一 tag 出现两次，
而 `stored_excerpts` 对重复编号是直接 `raise ValueError('引用编号重复…')` ——
这类论文在导出/复核时会硬失败，而不是给出可读的错误。

修法：`evidence.citations_for()` 按 tag 去重并保留首个，两处调用点统一改用它。

## 相邻片段补足（较小的一步）

同一份实测还记录了两条「待审」：`sentiment analysis` 限定不在当前引用片段里、
「可复用隐藏变量」缺相邻内容。这类是**chunk 边界**问题而非拆段问题。

`make_units` 现在会为「在句子/表格中间被切断」的引用片段补上**同论文的紧邻下一段**：

| 约束 | 取值 |
|---|---|
| 补足范围 | 只取同 `paper_id` 的下一个片段，**不跨论文** |
| 触发条件 | 被引片段结尾没有句末标点或收尾括号 |
| 每条陈述来源上限 | 仍为 **3**，补足项占用该额度；已有 3 个来源时不补 |
| 提示词可见性 | 补足项列在该条陈述的 `adjacent_sources`，与自身引用区分 |
| 判定口径 | 提示词明确：**片段不完整本身不构成「不符」**，只有原文陈述了不相容内容才判不符 |

补足项仍是真实片段、仍要逐字引用，页码照旧来自 chunk。没有为了减少待审数而放宽任何护栏。

## 验证：真实模型的前后对照

`tools/check_live_adjacent.py` 用真实提供方跑四个定向用例（合成片段，单次几百 token，
不是整篇论文）。同一组用例在**回退修复后**又跑了一遍，用来证明这个修复确实起作用
（否则只是一个"看起来对"的改动）。

| 用例 | 修复前 | 修复后 |
|---|---|---|
| 证据横跨被拆开的两段（同 tag） | `needs_review` —— 模型："只提到 hidden size 256 和分数下降，没有给出数值与 512→256 的比较" | `machine_supported`，证据 P1+P2 |
| 引用片段在表格边界截断 | `needs_review` —— "只说明 Table 3 列出结果，未建立是否复用隐藏变量" | `machine_supported` —— "相邻文本补全了这句话，确认在 sentiment analysis 中复用了隐藏变量" |
| 与原文方向相反（护栏对照） | `contradicted` | `contradicted` |
| 原文完全没有的信息（护栏对照） | `needs_review` | `needs_review` |

要点：**两个边界情形从待审变成支持，两条护栏没有任何放宽**。
两组用例分别消耗 576 / 523 token（合计约 1100），单条 3~8 秒。

- 新增 6 条回归（`tests/test_semantics.py`）：拆段拼接、前半段引用可核验、拆段不产生重复引用编号、
  截断片段获得相邻来源、相邻来源进入提示词、不跨论文且不超过 3 个来源、完整句子不补足。
- 完整回归 **639 passed / 1 skipped**（第三方 Starlette 弃用警告）。
- `ruff check` 本次改动的 5 个文件全部通过。
