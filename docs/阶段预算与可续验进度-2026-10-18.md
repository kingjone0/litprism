# N01：持久解读与可续验进度

更新：2026-10-26。文件名保留旧链接；当前已取消阶段调用上限，不再按预算暂停，也不提供手工额度编辑。本页只说明单篇新入口的实际运行/恢复，原实现与旧预算观察见[历史记录](history/N01阶段预算原始实现-2026-10-18.md)，后续任务见[唯一计划](实现计划.md)。

## 适用范围

论文详情统一的“解读论文/重新解读”使用analysis_runs/analysis_run_calls记录阶段、实际请求和每次尝试，不再另设“分阶段解读”按钮。兼容analyze API/普通任务、导入、对比、Skill和一次性CLI/MCP不自动获得此能力；新Web聊天有[独立持久请求协议](N04对话请求持久化与续验-2026-10-23.md)。当前schema为v15，无新迁移。

## 用户操作

1. 在论文详情选择“解读论文/重新解读”，先查看当前材料范围，按需关闭术语/机器辅助，无需填写阶段调用次数。文本不足时先补材料；已有运行通过同一记录查看/恢复。新建与精确恢复是不同动作。
2. 每次发送前登记尝试，成功后保存精确响应、实际输出参数、用量及阶段状态；推理token按服务上报计入，不保存思考正文。次数用于观测，不作为人为暂停条件。
3. 失败、取消或中断后查看运行记录，再选择检查/恢复。刷新、重启或只打开记录不会自动发远程请求。
4. 已成功且输入/配置精确匹配的请求复用原响应；失败或结果未知的尝试须明确允许重试，旧尝试和未知费用继续保留。
5. 原材料/版本、模型/协议/参数、实现或分析绑定变化时不复用旧运行，创建新运行；原正式解读不会被失败结果覆盖。

## 候选、分析与人工审核

完整提取完成后、机器复核开始前，独立保存ac_候选快照，绑定当前材料及父分析。机器关闭或后续失败仍可直接在右栏核对、修正、确认/拒绝/撤销，不必先取得模型支持；候选未经审核不作正式知识或正常导出。尚未实现每条提取指令完成即保存候选。

最终发布分析需要通过既有结构/来源/版本与运行检查；机器支持、原文覆盖及人工确认分别报告，不能因恢复成功就声称学术质量通过。N12切换材料保留历史块/分析，旧运行不能自动改绑新材料。

## 请求、用量与接口

能力已知时按实际模型窗口自动组织全文/超窗分批并分配输出；服务推理占输出。模型能力只读，不恢复旧4096/8192或整篇固定调用额度作为现行限制。完整公式/参数行为见[能力契约](模型能力与思考展示-2026-10-19.md)及[M03](modules/03-阅读提取与协作审核.md)。

| API | 行为 |
|---|---|
| GET /api/paper/{pid}/reading | 读取当前材料ID、范围/字符数、可否开始、已有分析及活动任务；不触发模型请求 |
| POST /api/paper/{pid}/analysis-runs | 创建独立运行并绑定材料/模型/配置 |
| GET /api/paper/{pid}/analysis-runs | 查看该论文最近运行 |
| GET /api/analysis-runs/{rid} | 查看安全运行明细、状态和用量 |
| POST /api/analysis-runs/{rid}/resume | 检查绑定后恢复；失败/未知是否重试由retry_failed明确表达 |

Web提交携带准备时的material_id，换版后拒绝静默替换；兼容调用未提供时仍受既有持久绑定/发布校验。当前应用内同论文已有活动任务时不重复排队；进度读取返回active/task_id。创建回执丢失先查看记录，不盲目重复创建。旧budgets仅兼容输入，不是手工限额；未知不等于免费，成功复用不算新质量样本。协作取消不能保证中断远端请求或撤销费用。

## 验证与数据边界

最新回归、真实整篇质量和证据根统一见[当前状态](当前实现与验收状态.md)。N01路径接通不代表N02整篇质量通过；所有测试/真实验收使用隔离根，不为读取配置迁移日常库。N08可备份相应记录，但只恢复新目录，密钥不随归档迁移。
