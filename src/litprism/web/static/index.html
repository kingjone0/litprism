导入论文

支持 PDF / DOCX / HTML / TXT / MD / TeX。导入时会对论文做真实性核验（Crossref · OpenAlex · arXiv 多源交叉验证）， 并自动生成结构化解读。

关于防幻觉设计

本系统的每一条外部文献都经过权威数据库交叉核验，核验结论分四级： ✅ 已核验（标题相似度 ≥ 0.92 或 DOI 精确命中）、⚠️ 疑似匹配（需人工确认）、 ❌ 未能核到（数据库无匹配，绝不等于该文献不存在，但一律禁止当作真实文献引用）、 ❔ 无法判定（数据源不可用，不会误判为"不存在"）。 问答环节还有两道闸门：无召回直接拒答；回答产出后逐条校验 [P1 p.3] 引用是否指向真实片段。

针对论文内容提问

回答只基于本地知识库中检索到的原文片段，每条结论都带 [P1 p.3] 来源标记； 系统会校验这些引用是否指向真实片段。材料不足时直接拒答。

文献推荐

候选文献全部来自 Crossref / OpenAlex / arXiv 的实时检索结果， 模型只负责写推荐理由、不能新增条目。可选择把通过核验的文献一键导入本地知识库。

论文真实性核验

这是本系统的核心防线：任何被引用的外部文献都必须先在权威数据库中命中。 核验会同时查询 Crossref、OpenAlex、arXiv（可选 Semantic Scholar），并按标题相似度 + 作者/年份佐证给出判定。

跨论文关联分析

基于 TF-IDF 余弦相似度计算论文间的词法相似性，并给出共享术语作为线索。 这只是线索，用于发现可能相关的论文；实质性关系判断请用「对比」功能。
